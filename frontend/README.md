# LogStream Analytics Dashboard

Frontend module for Project 2 — Distributed Log Analytics & Alerting Platform.

Scope follows the team work division:
- React dashboard scaffold and search/layout
- Search interface with service/log-level filters
- Search-result rendering
- Apache ECharts log-volume histogram
- Live Tail via WebSocket
- Alert configuration UI
- Integration-ready REST/WebSocket endpoints

Run:
npm install
npm run dev

Expected backend environment variables are in `.env.example`.
The exact API paths/contracts are configurable because the work-division document does not specify backend route names.
